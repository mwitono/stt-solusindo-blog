# STT Solusindo Blog: The 2026 ERP Playbook (ERP + AI Trends x Zoho)

A single-page blog post (bilingual EN/ID) covering the biggest 2026 ERP + AI
industry trends — sourced from McKinsey, CIO, IntelligentCIO, and Gartner —
mapped against what Zoho has actually shipped (Zia LLM, Agent Studio, Agent
Marketplace, Predictive Intelligence).

## Files

- `index.html` — the blog page (also served as GitHub Pages root)
- `blog-zoho-ai-erp-trends-2026-09-20.html` — same content, dated filename
  matching the STT Solusindo blog archive naming convention
- `cover-image-zoho-ai-erp-trends-2026-09-20.jpg` — hero cover photo

## Publishing to GitHub Pages

Enable GitHub Pages: repo **Settings → Pages → Source: Deploy from a
branch → Branch: main / (root)**. The post will be live at
`https://mwitono.github.io/stt-solusindo-blog/` within a minute or two.

- Everything is self-contained (inline CSS, no build step) — just static
